# CityMETER ศูนย์การค้า (Shopping centers) — owner preferences

Recorded 2026-10-25 (release 0.1.2, cache tag `20261025-r10`, data from the 16:39 export after the definition queue closed). Read `PRODUCT_STATEMENT.md` (0.8) and `DATA_METHOD.md` before changing what the page counts or argues.

- **Design system:** LDS 0.9.7 (`v0.9.7-owner.1`, `standalone-0.9.7-r1`, `color-srgb-10`, SHA-256 `d3085cbc…d432d96`). Colours come only from `assets/theme.css` and `js/scales.js`; never approximate a value by eye. Analytical scales use **all 41 samples** of the exact LDS LUTs (owner decision D8, 2026-10-25 — “scale สีให้ใช้ 41 สี ตาม LDS ทั้งหมด”): `buildRamp()` gives each value the LUT sample of its rank (lowest 0, highest 40, ties share, nothing interpolated) for district fills, province fills and the matrix, and `rampLegendHTML()` draws all 41 samples with value ticks; never a 3/5-class pick, a mixed colour or a per-theme value. Numbers on samples where neither ink reaches 4.5:1 sit on a neutral plate. Categorical groups use `landometer-series-10-v8` with a shape cue per group; no purple or brown, and series 2–3 stay unused because they collide with the orange density scale. No decorative brackets or coloured left rails; keyboard focus always visible.
- **Same look and behaviour as Luxury Brands** (`montri-th/luxurybrands`, 0.5): map-first CityMETER layout, 3D first paint, focus + quiet context, paper basemap from `js/map-style.js`, venue x-ray, camera presets (`city`, `model`, `eye` at venue level — always, see Venue camera — `plan` when 3D is off; every 3D preset at pitch ≤ 90° − fov/2 − 3°), breadcrumb with production codes. Do not reorder the host-building, massing and x-ray layers casually (see Luxury `AGENTS.md`).
- **Counting is the product (owner retail-venue definition 2026-10-23):** count only qualified, countable venues; supply excludes future projects and closed-by-evidence; parents never add their components; a qualified component whose parent is not qualified counts as its own venue only when it is a shopping centre or mall (owner decision D6, 2026-10-25: `ORPHAN_COUNTED_GROUPS`, `OWNER_SHOPPING_CENTRES`) and never when it is a possible duplicate; category rules the owner accepted and recorded in the registry (`owner_<rule>_definition_accepted_*`, `owner_confirmed_*`; decision D7) count as qualified with tier `owner`, and the venue panel always says so (“ผ่านนิยามตามกฎที่เจ้าของข้อมูลยอมรับ · <rule>”) — never as source evidence; records still awaiting review and records whose review closed unconfirmed (`reviewed_*_unconfirmed`, state `reviewed`) are quiet grey context labelled by state (zoom ≥ 11, hideable, searchable, outside the tab order) and never enter a number; negative determinations are not shown. Unknown `venue_qualification_status` values must be classified in `qualification_rule()`, and unknown `count_role` values of qualified rows in `COUNTED_ROLES` / `COMPONENT_ROLES` / `HELD_ROLES`, before publishing — the test suite fails until they are. A status that holds the count as a possible duplicate wins over a counted role. A parent the registry closed as context (`parent_context_*`, e.g. ดุสิต เซ็นทรัล พาร์ค) is a negative determination: not shown, not counted; its qualified retail child counts on its own (D6, decision D15).
- **Aha first (D1):** the first view frames the three districts with the highest venues/km² in the province of the densest district and states the share, numerator, denominator and area context, computed from the data every time (`js/area-insight.js`). No onboarding gate; no caveat banner on the first view. Snapshot numbers in docs are fixtures, not UI constants.
- **Areas are official boundaries:** membership is precomputed point-in-polygon on full-resolution OpenGISData-Thailand districts (`provinceCode`, `districtCode`); never assign by name or nearest area; district and province ids are CityMETER production codes.
- **Size (D3):** legacy GLA/GFA estimates appear only in the venue panel (figure with “ราว” on screen, method in the evidence list); never in filters, charts, tables, totals or rankings. The full dataset name “ศูนย์การค้าและสถานที่ค้าปลีก: จำนวน ประเภท และผู้บริหาร” (D2) stays as an alternate name in metadata; the title is “ศูนย์การค้า” (D10).
- **Evidence per field:** every value in the venue panel carries its basis, public source link and check date when available; missing is “ยังไม่มีข้อมูล”, never 0; conflicts keep both sides. Operator charts say “สัดส่วนจำนวนสถานที่”, never market share.
- **Public files carry no private links:** no `docs.google.com` / `drive.google.com` URLs and no Drive/Sheets file ids anywhere in the repository (a test scans every text file). Research Master and Dataset Registry are internal working references; the pitch documents and team statement stay internal.
- **Scale:** the registry may grow to thousands of qualified venues. Keep all venues on GPU layers, DOM pins only for the focus (≤ 600), logos ≤ 250 at zoom ≥ 14 inside the focus, detail shards sized by `shard_count()`, and the table paginated.
- **Data refresh:** `npm run data:refresh -- <csv-export-dir> <geometry-bundle-dir> [<logo-dirs>]`, then read `data/build-report.json`. Logos are used only when their bytes match the sheet SHA-256; lookup by `venue_id` only; collecting files is not a trademark licence. When logo files arrive through a Drive connector as base64 text, never retype the text (long repeated runs drift): save the tool result with a script and keep only files whose SHA-256 equals the sheet.
- **Copy:** short, natural Thai: สถานที่ · ศูนย์การค้า · คอมมูนิตี้มอลล์ · ตลาด · สถานีบริการ · ผู้บริหาร · ร้านข้างใน · แห่ง · เขต/อำเภอ · กำลังจะเปิด · ปิดแล้ว · ยังยืนยันไม่ได้. Units and provenance live in the data line; methods and limits in the evidence list, help and docs. No “ทำเลทอง” or “ช่องว่างตลาด” claims.
- **Title (owner 2026-10-25):** TH “ศูนย์การค้า”, EN “Shopping centers” in the header, `<title>` pattern “[page] · ศูนย์การค้า · CityMETER”, H1, metadata and docs. The meaning stays shopping centres and retail venues under the owner definition; body copy that counts all groups says “สถานที่ค้าปลีก”.
- **Aha first, no caveats on screen (owner 2026-10-25):** the visible panel states facts in the words of the ICP (ผู้เช่าและทีมขยายสาขา, ทีม leasing, นักลงทุน: ย่าน · สถานที่ค้าปลีก · ผู้บริหาร · ร้านข้างใน · กำลังจะเปิด · ปิดแล้ว). Methods, bases, “ไม่ใช่ …” notes, coordinate roles, hours scope and the D3 size method live in the collapsed “หลักฐานรายช่อง” list, the help and the docs — a test strips `<details>` and fails on caveat words left on screen. Keep one compact provenance line (dataset · source · date · boundary) under every panel with numbers; missing key fields still read “ยังไม่มีข้อมูล”.
- **Pin buildings (owner 2026-10-25: “หมุดศูนย์การค้า ทั้ง 8 ประเภท … ถ้า mapped กับ 3d building ได้ก็ต้องแสดง 3d building ทั้งหมด”):** `js/pin-buildings.js` maps every counted pin in view (zoom ≥ 14) to the OpenMapTiles building polygon it stands in, or within 3 m of its edge, per polygon part (OpenFreeMap merges equal-height buildings into one MultiPolygon per tile — never select or hide by feature id alone), with building:parts for outlines and the same building's piece in the next tile; drawn in the host blue through `buildings.js`; validated host geometry always wins; never by name or nearest building. The panel says which kind it is.
- **City massing reads everywhere:** the city tier's fade is measured from the venue points of the focus and from the camera centre (re-anchored every 300 m at zoom ≥ 12.5), and a merged feature fades by its nearest part; the venue view focuses a 650 m ring round the venue. Do not go back to boundary vertices or a feature's first coordinate as anchors.
- **Venue camera (owner 2026-10-25 18:49: “tap a pin or a building → the 3D building in two-point perspective, zoom to fit the viewport, always”):** `frameVenue()` → `fitBuilding()` (`js/camera.js`): eye preset (pitch 75°, fov 24°), padding zero so the principal point is the canvas centre and the horizon stays out of the frame; bearing = dominant wall direction + 45° (`twoPointBearing()`), the diagonal where the family's other drawn buildings hide least, then the one nearest the current bearing; every footprint and roof vertex fits the free box (`visibleBox()`: below the toolbar, above the map card, legend, charts bar, table or open sheet, left of the zoom control) and fills one side. No building known yet → a 90 m box round the pin, then one turn to the building when the pin matcher finds it (≤ 2 re-frames, never after a user camera move). Every way in (pin, building, x-ray, list, search, URL) frames again. GeoJSON sources use `maxzoom: 22` (`GEOJSON_MAXZOOM`): MapLibre 5.6.2 throws in `_updateRetainedTiles` between maxzoom − 1 and maxzoom with a pitched camera.
- **Phones: the map first (owner 18:49):** no selection opens the bottom sheet; the map card (`#map-aha`, `mapCard*()` in `js/panel.js`) carries the level's reading — Aha, venue logo/name/strongest figure, district, record, search — with one primary button “ดูรายละเอียด” (`open-panel`). Opening or closing the sheet re-frames the venue in the new free box; the map attribution moves above the card (`--map-card-space`).
- **Venue panel (owner 18:49: name and logo first, concise, no caveats):** detail levels (`#panel.is-detail`) hide the dataset heading (kept for screen readers), search and filters; the back button sits in the breadcrumb row (`#panel-back`). `renderVenue()` order: logo + name → status → key figures (reported values only; the D3 estimate stays a “ราว” fact line) → contact chips → short facts; coordinates, the bracketed hours note, an address in another province and “no building found” live in “หลักฐานรายช่อง”.
- **Charts:** amCharts 5.20.8 self-hosted in `vendor/amcharts5/` with its LICENSE (free linkware licence: the amCharts logo stays; never add a licence key or hide the logo), loaded only when the chart panel opens, HTML fallback kept. Colours from the page tokens and the map ramp; keyboard focus groups with Enter to drill down. Operator charts show named operators; the long tail and “ยังไม่ระบุผู้บริหาร” are counted in the caption. Every view and its caption count the same rows: venues with a point inside a district of the province being read (or of the country). Numbers on one screen must add up — rows no district holds (no point, or a point outside every boundary line) are named once in the panel (“อีก k แห่งยังระบุเขต/อำเภอไม่ได้”) and listed in the table.
- **Icons:** LDS Material Symbols Rounded, FILL 0 / wght 300 / GRAD 0 / opsz 24. nav-7 bytes stay unchanged; UI and metric glyphs come from `assets/icons/material-pictogram-300.woff2` (40 roles, rebuilt with `scripts/build-pictogram-font.py`, which also writes the glyph block of `styles.css`) — a test exception, not yet an LDS-registered subset. An icon always sits next to a label (icon-only only for a conventional control with an accessible name).
- **Release:** review actual Thai and English at 390 px and desktop in light and dark before calling a change done. Bump the `?v=` tag on the entry scripts and stylesheets in `index.html`, then run `python3 scripts/build-static.py` — its import map gives every module in `js/` the same tag, so browsers never mix cached older modules with a new release. Local renders are not proof of a live release: push, wait for Pages, run `npm run handoff:manifest` and `npm run verify:live`, and check the live page in a real browser.
