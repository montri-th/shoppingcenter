# CityMETER Shopping Centers & Retail Venues — owner preferences

Recorded 2026-10-25 (release 0.1.0). Read `PRODUCT_STATEMENT.md` (0.3) and `DATA_METHOD.md` before changing what the page counts or argues.

- **Design system:** LDS 0.9.7 (`v0.9.7-owner.1`, `standalone-0.9.7-r1`, `color-srgb-10`, SHA-256 `d3085cbc…d432d96`). Colours come only from `assets/theme.css` and `js/scales.js`; never approximate a value by eye. Analytical scales use the exact 41-sample LUTs and LDS class tables (3 or 5 here — never a 2- or 4-colour set, never mixed colours) with the same HEX on light and dark. Categorical groups use `landometer-series-10-v8` with a shape cue per group; no purple or brown, and series 2–3 stay unused because they collide with the orange density scale. No decorative brackets or coloured left rails; keyboard focus always visible.
- **Same look and behaviour as Luxury Brands** (`montri-th/luxurybrands`, 0.5): map-first CityMETER layout, 3D first paint, focus + quiet context, paper basemap from `js/map-style.js`, venue x-ray, camera presets (`city`, `model`, `eye` at venue level only, `plan` when 3D is off; every 3D preset at pitch ≤ 90° − fov/2 − 3°), breadcrumb with production codes. Do not reorder the host-building, massing and x-ray layers casually (see Luxury `AGENTS.md`).
- **Counting is the product (owner retail-venue definition 2026-10-23):** count only qualified, countable venues; supply excludes future projects and closed-by-evidence; parents never add their components; a qualified component whose parent is not qualified counts as its own venue only when it is a shopping centre or mall (owner decision D6, 2026-10-25: `ORPHAN_COUNTED_GROUPS`, `OWNER_SHOPPING_CENTRES`) and never when it is a possible duplicate; pending records are quiet grey context (zoom ≥ 11, hideable, searchable, outside the tab order) and never enter a number; negative determinations are not shown. Unknown `venue_qualification_status` values must be classified in `qualification_rule()` before publishing — the test suite fails until they are.
- **Aha first (D1):** the first view frames the three districts with the highest venues/km² in the province of the densest district and states the share, numerator, denominator and area context, computed from the data every time (`js/area-insight.js`). No onboarding gate; no caveat banner on the first view. Snapshot numbers in docs are fixtures, not UI constants.
- **Areas are official boundaries:** membership is precomputed point-in-polygon on full-resolution OpenGISData-Thailand districts (`provinceCode`, `districtCode`); never assign by name or nearest area; district and province ids are CityMETER production codes.
- **Size (D3):** legacy GLA/GFA estimates appear only in the venue panel with their method; never in filters, charts, tables, totals or rankings. The dataset name is “ศูนย์การค้าและสถานที่ค้าปลีก: จำนวน ประเภท และผู้บริหาร” (D2).
- **Evidence per field:** every value in the venue panel carries its basis, public source link and check date when available; missing is “ยังไม่มีข้อมูล”, never 0; conflicts keep both sides. Operator charts say “สัดส่วนจำนวนสถานที่”, never market share.
- **Public files carry no private links:** no `docs.google.com` / `drive.google.com` URLs and no Drive/Sheets file ids anywhere in the repository (a test scans every text file). Research Master and Dataset Registry are internal working references; the pitch documents and team statement stay internal.
- **Scale:** the registry may grow to thousands of qualified venues. Keep all venues on GPU layers, DOM pins only for the focus (≤ 600), logos ≤ 250 at zoom ≥ 14 inside the focus, detail shards sized by `shard_count()`, and the table paginated.
- **Data refresh:** `npm run data:refresh -- <csv-export-dir> <geometry-bundle-dir> [<logo-dirs>]`, then read `data/build-report.json`. Logos are used only when their bytes match the sheet SHA-256; lookup by `venue_id` only; collecting files is not a trademark licence.
- **Copy:** short, natural Thai: สถานที่ · ศูนย์การค้า · คอมมูนิตี้มอลล์ · ตลาด · ผู้บริหาร · แห่ง · เขต/อำเภอ. Units, provenance and limits live in the data line, help and docs. No “ทำเลทอง” or “ช่องว่างตลาด” claims.
- **Release:** review actual Thai and English at 390 px and desktop in light and dark before calling a change done. Local renders are not proof of a live release: push, wait for Pages, run `npm run handoff:manifest` and `npm run verify:live`, and check the live page in a real browser.
